# Live Smoke Test Guide (Unstuck v1.0.1)

This guide provides step-by-step instructions for manually verifying **Unstuck v1.0.1** in real Google Chrome on live coding platforms (such as `leetcode.com/problems/two-sum`), specifically confirming the resolution of the canned response / ungrounded quote bug.

---

## 1. Extension Installation

### Option A: Load Unpacked (Development)
1. Build the extension:
   ```bash
   npm run build
   ```
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** and select the `.output/chrome-mv3` folder inside this repository.
5. Verify **Unstuck** appears with version **1.0.1** and no errors.

### Option B: Packaged Release (.zip)
1. Verify the release archive `.output/unstuck-1.0.1-chrome.zip` was generated by `npm run zip`.
2. Extract the `.zip` archive into a local folder.
3. Load the extracted folder via **Load unpacked** in `chrome://extensions/`.

---

## 2. Initial Setup & BYOK Configuration

1. Click the Unstuck puzzle icon in the Chrome toolbar to open the Popup, or open the Options page: `chrome-extension://<id>/options.html`.
2. Complete the onboarding wizard (or navigate to Settings):
   - **Consent:** Enable stuck detection for `leetcode.com`.
   - **API Key:** Enter your real Google Gemini API Key (`AIza...`) and click **Test Connection**.
   - Verify green checkmark: *"Connected (X ms)"*.
3. Save settings.

---

## 3. Real Chrome Reproduction Test (Two Sum)

1. Navigate to: `https://leetcode.com/problems/two-sum/`.
2. Open Chrome Side Panel (or click the Unstuck icon in toolbar and open Side Panel).
3. Switch to the **Chat** tab in Unstuck Tutor.

### Test Case 1: Off-Topic / Meta Question
- **Query:** `who invented this problem`
- **Expected Behavior in v1.0.1:**
  - Assistant responds honestly (e.g., explaining that problem authorship is not specified in the LeetCode statement text).
  - It does **NOT** dump a Two Sum hash table hint.
  - Critic badge: Displays `Critic: Checked` with no fake quoted text (`groundedQuote` omitted or honest).

### Test Case 2: Approach Question
- **Query:** `how would be the approach`
- **Expected Behavior in v1.0.1:**
  - Assistant provides an intuitive approach explanation tailored to Two Sum (e.g., hash table lookup or two-pointer on sorted input).
  - Grounded quote (if rendered): Quotes actual text from the problem statement (e.g. `an array of integers nums and an integer target`).
  - Level chip: Reflects current level (e.g. L1/L2) with appropriate conceptual explanation.

### Test Case 3: Short Follow-up
- **Query:** `how?`
- **Expected Behavior in v1.0.1:**
  - Distinct response tailored to the follow-up, NOT identical to the previous query.
  - Responses for query 1, query 2, and query 3 are **all distinct**.

---

## 4. Grounding & Critic Badge Verification

1. When the agent graph successfully verifies leak-safety and substring grounding:
   - Green badge: `Critic: Checked` (with checkmark icon).
2. When model confidence is low ($\le 0.48$):
   - Amber badge: `Low confidence` with tooltip warning *"Treat it as a guess"*.
3. When network fails or fallback activates:
   - Outline badge: `Critic: Unverified`.

---

## 5. Trace Tab Inspection (Real Telemetry)

1. Click the **Trace** tab in the Side Panel header.
2. Confirm the following:
   - **No traces?** Displays clean empty state: *"No agent traces recorded yet. Traces appear here after asking questions or receiving hints."*
   - **After chat query / hint:** Displays real execution card with:
     - Model name (e.g., `gemini-2.5-flash`).
     - Real node breakdown timings: `detector`, `planner`, `context_builder`/`hint_generator`, `critic`.
     - Actual token usage counters (prompt / completion tokens) from the Gemini API response metadata.
     - Verified absence of hardcoded values (`12ms`, `1.8s`, `1,842 / 4,000`, `94%`, `leetcode:stuck_high:mastery_medium`).

---

## 6. Progress Tab Inspection

1. Click the **Progress** tab.
2. Confirm:
   - Zero problems solved shows clean empty state: *"No topic mastery recorded yet. Start solving problems to track Bayesian Knowledge Tracing scores."*
   - Solved count shows `0` (or real count if problems were completed via "I solved it!"), without fake sparklines or hardcoded `+2 vs last week`.

---

## 7. Error Resilience & Recovery (S13 Cards)

1. **Invalid API Key:**
   - In Settings, enter an invalid key (e.g. `AIzaFakeKey1234567890`) and ask a question.
   - Verify S13.1 card appears: *"Invalid API Key"* with direct link to Settings. No canned assistant answers.
2. **Offline Simulation:**
   - In Chrome DevTools Network tab, set network to **Offline**.
   - Send a query or request next hint.
   - Verify S13.2 card appears: *"Network Offline"* with Retry button.
